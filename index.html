Capabilities

not a chat window

Six specialist agents route through one core brain — with approval gates, an audit trail, and offline fallbacks at every step.

Vision that respects the room

Adaptive capture from 3 s down to 15 s when the screen is static, change-detection before OCR, an app block list, and a red observing dot whenever it watches.

vision_agent.py · permission-gated

Coding

Trust & privacy

Local first.
Approval always.

Capture, OCR, speech and memory run on the PC. Only reasoning calls out — and a screenshot leaves the machine only when you ask about the screen.

Read the privacy architecture

Encrypted memoryFernet-encrypted transcripts and entities; the key lives in Windows Credential Manager. “Forget everything” is a hard delete.

Confirmation gateShell commands, file writes, and anything that would send, submit, pay or delete waits for approval on PC or phone.

Private modeOne toggle — panel, phone, or voice: no capture, no memory writes, nothing to the cloud. The pill turns gold.

Audit trailEvery auto-approval in trust mode is logged and toasted. Destructive commands and payment buttons always ask.

Kill switchesComputer control refuses when disabled; slam the mouse to the top-left corner to abort any automation instantly.
